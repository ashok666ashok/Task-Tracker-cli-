# Task Tracker CLI

CLI tool -> manage tasks. Pure Node.js. No external libs. Data -> local JSON file.

## Features

* Add, update, delete tasks.
* Mark status (`todo`, `in-progress`, `done`).
* List tasks (all, `done`, `todo`, `in-progress`).
* Auto-create JSON DB.
* Track `createdAt`, `updatedAt`.
* Commands `add <description>`, `update <id>`, `delete <id>`, `list`, `list-<status>`, `mark-<status> <id>`
